cloudcn

Copy-paste WebGL cloud components for React and Tailwind, in the style of shadcn/ui.

Seven components on transparent backgrounds: volumetric clouds, thin streaks, fog and a full sky. Free and MIT licensed. Copy the source into your project or use the shadcn CLI.

Source on GitHub · Component registry · Full text guide

Components

  • Nimbus: Fair-weather volumetric cumulus. Drag to orbit.
  • Dusk: Low-sun light, warm edges and violet shadows.
  • Tempest: Storm tower with an anvil top and lightning.
  • Horizon: Wide cloud bank for a hero base or divider.
  • Wisp: Thin high streaks behind text.
  • Haze: Low fog that thickens toward the bottom edge.
  • Stratus: Full cloud sky.

Install a component

npx shadcn@latest add "https://cloudcn.pages.dev/r/nimbus.json"

For manual installation, see the usage guide. Tailwind v4 and an @ alias pointing to src are assumed.

Rendering and limits

Nimbus, Dusk, Tempest and Horizon share a raymarched volume renderer. Stratus has its own raymarched sky. Wisp and Haze use layered shaders. A static SVG cloud appears if WebGL is unavailable or fails.

Procedural clouds, not photographs. Tested in headless Chrome with software rendering; real phone GPU speed is not measured.
